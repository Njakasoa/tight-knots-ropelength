# M1 acceptance gate

A PASS requires stored evidence for every mandatory row. No silent substitutions.

| Requirement | Evidence required | Initial status |
|---|---|---|
| Environment audit | versions, hardware, actual commands/failures | in progress |
| Normalization | radius, smooth vs polygon, links | in progress |
| Current bibliography | primary sources, cutoff and proof status | in progress |
| Ridgerunner reproduction | real run and reference comparison | pending |
| Independent thickness | cases incl. vertices, edges, collisions | pending |
| Topology | constructive families + independent geometry checks | pending |
| Unknot control | 2pi and resolution/scaling checks | proof drafted |
| Trefoil control | sourced tight coordinates + numeric comparison | pending |
| Simple torus link | Hopf and T(Q,Q) test | proof drafted |
| Certified upper demo | checked analytic geometry + interval length | pending |
| Contact extraction | stored pairs/kinks/tolerances | pending |
| Independent reviewer | actual Astra review, findings resolved | pending |

A partial infrastructure success does not satisfy M1. M2 starts only after a PASS.
A mathematical candidate discovered during M1 is permitted, but does not bypass
these controls or justify a paper before its proof and novelty have survived review.
