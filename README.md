# Tight Knots Lab

Reproducible geometric knot research. Thickness is the tube **radius**; ropelength
is total contour length divided by that radius, including all link components.

Status: M1 under construction. No new ropelength theorem or global optimum claimed.
The full authorized programme is in RESEARCH_MISSION.md. M2 is gated by M1_REVIEW.

Start with NORMALIZATION.md, ENVIRONMENT_AUDIT.md, STATE_OF_THE_ART.md and NEXT.md.
Numerical evidence, topology verification, certified bounds and publication novelty
are separate fields throughout. Dependencies and downloaded sources live locally;
no paid compute, publication or external contact is authorized.
